# Session logs

One file per working session, named `<user>_<YYYY-MM-DD_HHMM>.md`, for example `alex_2026-10-01_1430.md`. The name is the `user_time` id: the developer's first name in lowercase and the local start time.

- Create it at the start of the session from `../session-log-template.md` and fill it in as you work.
- It records every change made in the session and every decision made outside the docs.
- Never edit another person's log. Add a new one instead.
- Commit it with the same pull request as the code it describes.

See `../HANDOVER.md` for the full process.
