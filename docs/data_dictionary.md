# Data dictionary

Generated by `scripts/make_data_dictionary.py` from the live database on 2026-10-05 07:28 UTC. Do not edit by hand: change the migration, then re-run the script.

Covers every table of data model v2 (docs/specs/data-model-v2.md): Bronze, Silver, Gold, App, Reference and Operations. The six views are listed in section 1b of that document.

**How to read it.** *Required* means the column cannot be empty. `NULL` always means "no data", never zero. *Unit* is the canonical unit stored (conversion to other units happens only in the API). *Source flag* names the column that says where a row came from: `source` / `entry_source` hold `manual`, `scan`, `file_import`, `cgm`, `replay`, `system`, ... and `demo_dataset` marks data derived from the cited datasets (simulated or imported); `estimated_by` says who produced a nutrient value. All times are UTC.
